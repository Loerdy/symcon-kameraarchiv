# Kamera-Archiv für Symcon

Snapshots von Kameras per Auslöser (Klingel, Türkontakt, Bewegungsmelder …) aufnehmen und je Kamera in einem Archiv ablegen – mit Kachel-Visualisierung, neueste Bilder zuerst.
